# Enhancement 1: Software and Design

  The CS 350 prototypical thermostat comes about from Module 7 of that course.  
In this particular assignment and in the ones preceding it, we were tasked with setting up Raspberry Pi hardware and programming LEDs on the board to correspond with temperatures that could be changed via pressing buttons attached to the board. I plan to take the original file that made the thermostat functionality of the Raspberry Pi and translate into a C application that carries the same functionalities as the original as a baseline while also eliminating some of the originally inherent issues like those involving resource optimization. 

  I selected this artifact because, not only is it particularly recent in my degree program,  
but it’s also been one of the most challenging. I struggled with the hardware, but I believe that  
made me grow as a programmer. By building a C framework from scratch rather than relying on the  
original script’s library in Python, I’m demonstrating an ability to improve flawed programming  
in hardware and an ability to build on it. By designing and evaluating computing solutions, I’m  
proving able to remediate the glaring problems that already exist in the prototype, like delayed  
or missing inputs and memory issues by mitigating the latency through asynchronous state loops.   
By translating the entire script from Python to C, I also demonstrate an ability to select and   
deploy new tools while using problem-solving skills to navigate complicated hardware issues. 

  Even though currently the artifact has some hardware mockups, I believe it is meeting my goals,  
particularly through its forecasted conservation of resources.  

  I believe I am meeting my course outcomes of 3, 4, and 5. I designed the software to accommodate  
people with a wide range of available resources, meaning RAM. I am using inherent design quirks of  
C to make the thermostat run more efficiently, and I am building a security mindset to make that  
actually happen. There were a lot of flaws in the original program that I am looking to circumvent.  
Because two of the three files I previously outlined were more demonstrative, I’ve decided to go  
forward with just one of the files as my artifact, seeing as the original was over six hundred  
lines and incredibly involved and improving it alone can give me a well-built thermostat. 

Time management has been something I’ve needed to hone while working on this artifact. I’ve come to realize through the code review that, even when you know a program, it takes a lot to sift through it and translate it. As aforementioned, the original files were large. There are also learning curves, seeing as Python and C work differently. More time needs to be allotted to be able to support such a large project.
